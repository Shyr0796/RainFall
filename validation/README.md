# RainFall validation workspace

本目录将“代码是否正确”“数值解是否收敛”“参数是否可校准”“未见数据是否可预测”“真实事件是否可信”分开记录。任何实验只有在原始数据、运行日志和结果文件同时存在时，才标记为 `completed`。

## 本轮结论

- 数值/代码检查 9 项通过、0 项失败、3 项跳过或仅报告；CUDA 一致性因无可用后端未执行。
- UK EA Test 1 完整执行，峰值水位误差 1.60--1.79 mm，最终水位误差约 5.31--5.33 mm；属于标准数值基准，不是实测验证。
- Freiburg 132 组人工降雨实验按完整站点划分：28 个盲测事件上，常量损失率体积 NSE 0.487，土壤状态模型为 0.742。该结果只约束入渗—产流子机理。
- 城市 LSPIV 已运行诊断基线，但表面速度与深度平均速度不可直接等同，因此标记为 `partial`。
- Fourmile Creek 实测水位/流量/水痕已整理；当前核心缺少河道几何和指定水位/流量边界，真实事件模拟被如实阻塞。
- 高级城市水槽协议已用三构型率定并锁参盲测：4/5 构型执行，但水深、分流、方向与稳态门槛未通过；`BD` 被几何门控阻止，不能作为论文级验证成功。
- NYC FloodNet 官方快照已审计 2,776 个事件和 337,767 个水深点；真实城市观测目标已就绪，尚未组装同步降雨、潮位、DEM 与排水边界。
- USGS Muddy Creek 完整模型档案已下载校验，含 DEM、糙率、降雨存储、二维几何、7 站 497,845 条水位记录；公开数据充分，当前阻塞转为 DSS/边界/空间适配开发。
- 城市 GIS 生产核心已完成合成回归：GeoTIFF 与 Shapefile 在 EPSG:32650/2 m 网格严格对齐，建筑面积误差为 0，建筑内水深与跨建筑通量为 0，相对水量闭合约 `1e-8`；这属于代码/几何验证，不是实测验证。
- 建筑高度—DEM 耦合已用 752 个 NYC 官方高度建筑和 NOAA 2017 裸地 DEM 实跑：单位/基准/公式和 solid-mask 水动力不变性门控通过；但 `GROUNDELEV` 对 DEM 的绝对误差 p95 为 2.61 m，因此只作 QC，禁止替代 DEM。这属于官方数据耦合诊断，不是洪水事件验证。

直接打开 [`validation.html`](validation.html) 查看提案、执行状态、结果图、指标和论文结论边界。

## 目录约定

- `validation.html`：面向论文设计的中文总提案与结果总览。
- `common/`：跨实验复用的指标和数据校验代码。
- `experiments/<id>/data/raw/`：保持原样的官方数据。
- `experiments/<id>/data/processed/`：带生成脚本的派生数据。
- `experiments/<id>/code/`：可复现实验代码。
- `experiments/<id>/results/`：CSV、JSON 和图表。
- `experiments/<id>/logs/`：命令、环境和标准输出。
- `advanced/`：期刊级锁参盲测、真实城市传感器和独立降雨洪水实验；含用户数据需求清单。

## 状态定义

- `completed`：数据、代码、实际运行结果和质量检查均存在。
- `partial`：完成了可验证子集，但仍缺关键输入或模型能力。
- `blocked`：外部数据或必要物理过程不可用；必须记录阻塞证据。
- `planned`：尚未开始，不能作为验证证据。

## 复现原则

1. 原始数据不覆盖、不手工修改；派生步骤写成代码。
2. 数据源、版本、许可证、下载时间、文件大小和 SHA-256 均登记。
3. 校准事件与盲测事件按完整实验或事件划分，不按随机观测点拆分。
4. 高保真模型互比只称“模型互比”，不称“实测验证”。
5. 失败工况和未定义指标保留，禁止用删样本制造漂亮结果。
