# RainFall 高等级验证计划

## 目标与结论边界

本阶段把现有的“数值验证 + 子机理验证”升级为三个相互独立的证据层：

1. **受控城市水槽盲测**：验证多入口、多出口、建筑阻隔条件下的水深、出口分流、速度与方向。
2. **真实城市街道积水验证**：使用 NYC FloodNet 的传感器位置、峰值水深、起涨、退水和逐事件时序，验证真实城市事件的点位过程。
3. **降雨驱动城市河流事件验证**：使用 USGS Muddy Creek 的实测降雨事件、压力传感器、高水痕、DEM、模型档案和淹没深度图，验证从降雨/边界到水深与范围的完整链条。

生产核心的前置能力另由 `10_urban_gis_core` 回归：统一 CRS、建筑屋顶 DEM 与固体占据、空间降雨/入渗/糙率、指定流量/固定水位边界和容量受限排水汇。`11_building_dem_datum` 又用 752 个 NYC 官方高度建筑和 NOAA 裸地 DEM 验证了英尺—米转换、NAVD88 契约、相对屋顶公式和建筑固体掩膜；实测同时否定了直接用 `GROUNDELEV` 替换 DEM。这两项通过只说明代码与数据耦合受控，不替代上述三条观测验证。

只有第 1--3 层均完成，才能使用“validated for the evaluated laboratory and real-event conditions”一类有限域结论；不能外推到未验证城市、排水系统或降雨类型。

## 实验 07：城市水槽多构型盲测

- **校准构型**：`Ref`、`CE`、`CO`，覆盖参考街区、空中央区和连续街道网络。
- **盲测构型**：`Px5`、`Py5`、`BU`、`BS`、`BD`；任何盲测结果产生前冻结参数和边界标签。
- **待校准量**：统一 Manning $n$；可选全局表面/深均速度比例 $\alpha$，不能逐构型单独拟合。
- **主要观测**：入口水深、三个出口流量及其分流比例。
- **次要观测**：LSPIV 方向；速度模长只有在预注册 $\alpha$ 后才作为正式指标。
- **稳态规则**：连续 30 s 内域内储水变化率 < 0.1%/s，且总出口与入口流量差 < 2.5%。
- **网格规则**：至少比较 1、2、4 cm；报告 GCI 或三网格误差趋势。
- **通过门槛**：入口水深 MAE ≤ 2 mm；出口分流总变差 ≤ 0.05；方向 MAE ≤ 20°；反向流错误面积 ≤ 5%。门槛在盲测前冻结。
- **本轮实跑**：`Px5/Py5/BU/BS` 已锁参执行，`BD` 因观测派生掩膜缺少出口 2 而被几何门控阻止。四构型平均入口水深 MAE 3.94 mm、分流总变差 0.219、方向 MAE 31.98°；守恒通过，但精度和稳态门槛失败，因此不能写作正式验证成功。

## 实验 08：NYC FloodNet 真实街道积水

- 按完整暴雨事件划分，不随机拆传感器分钟记录。
- 不预先凭事件名挑选；由 `08_nyc_floodnet/code/audit_floodnet.py` 按完整官方快照自动构建风暴簇并排序，再在查看模型结果前冻结事件划分。
- 使用一组事件校准 Manning、状态型入渗和等效排水率；其余事件完全盲测。
- 主要指标：峰值水深 MAE/RMSE、起涨 MAE、峰现 MAE、退水 MAE、超过 0.10/0.30/0.60 m 的 CSI/POD/FAR。
- 必须分别报告潮汐影响和非潮汐传感器；没有管网资料时不得把退水误差解释为地表求解器误差。
- 传感器不发生积水的连续负样本需要向 FloodNet 申请全连续分钟流；仅使用公开事件表时不能计算完整误报率。
- **本轮实审**：2,776 个事件、286 个发生过事件的传感器、337,767 个水深点；96 条事件至少触发一个汇总/时序/部署 QC 标志，全部保留在 `flagged_events.csv`。

## 实验 09：USGS Muddy Creek 降雨驱动验证

- 核心实测事件包括 2019-09-28、2021-03-17、2021-04-29、2021-05-27、2021-06-25。
- 推荐划分：2021-05-27 与 2021-06-25 校准；2021-04-29 完全盲测；2021-03-17 外部复核；2019-09-28 只有高水痕，作为峰值空间约束。
- 输入：公开 DEM、雨量/水文边界、土地覆盖和模型几何；参数在盲测前冻结。
- 观测：压力传感器时序、高水痕、参考流量和公开淹没深度/范围。
- 主要指标：水位 RMSE/峰值/峰现、HWM MAE、范围 CSI/POD/FAR、水深分级 F1、水量闭合。
- HEC-RAS 输出只用于互比和误差定位，不能替代 PT/HWM 实测验证。
- **本轮实审**：完整档案 MD5 和 ZIP 结构通过，966 个文件；提取 7 站、497,845 条水位记录和 28 个事件—站点目标，确认 DEM、糙率、DSS 降雨存储与二维几何齐全。尚未转换 DSS 或运行 RainFall。

## 不确定性与统计设计

1. 观测误差、DEM 误差、Manning、入渗、排水率和边界误差分别建模；不得只给一个最优参数结果。
2. 校准使用多目标损失：体积、水深时序、峰现和空间范围；保持失败事件。
3. 最终表格报告中位数、四分位数、95% bootstrap 区间和逐事件结果。
4. 做参数可辨识性检查；如果多组参数产生相同水深但不同流量/速度，应把参数表述为等效参数。
5. 对高危险区域额外报告漏判面积和漏判持续时间，不能只用总体 RMSE。

## 面向期刊的最低证据包

- 可复现代码、环境、原始数据哈希、校准/盲测清单和失败事件。
- 受控实验中至少 5 个未见城市构型。
- 至少 1 个真实事件完全盲测；更稳妥的是 2 个校准 + 2 个盲测事件。
- 网格、时间步、观测算子和参数不确定性分析。
- 清楚声明局部惯性方程不覆盖强平流、陡峭溃坝波、地下管网回涌等过程。
