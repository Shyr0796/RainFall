# 若验证用户自己的目标城市，需要提供的数据

公开数据足以完成通用方法论文的高级验证；如果论文结论要落到用户自己的城市或项目区域，请提供以下资料。优先提供原始文件，不要截图或手工重采样。

## 必须项

1. DEM/DSM：GeoTIFF，坐标系、分辨率、垂直基准和采集日期明确；最好同时有裸地 DTM 与建筑 DSM。
2. 降雨：雨量站或雷达格点的原始时序，至少 5--10 min 分辨率；包含站点坐标、时区和质量标志。
3. 事件水深/水位：传感器原始时序或带时间戳的人工观测；包含传感器地面高程和垂直基准。
4. 排水边界：河道/外水位、泵站、闸门和出口运行记录。
5. 事件清单：哪些事件用于校准、哪些必须封存为盲测；建议在查看模型结果前确定。

## 城市内涝强烈推荐项

- 管网拓扑、管径、井底高程、溢流口、泵站曲线和堵塞记录。
- 道路路缘、下穿通道、围墙、桥涵和建筑轮廓。
- 带经纬度和拍摄时间的照片/视频、水痕或道路封闭记录。
- 土地覆盖、土壤类型、前期降雨和初始含水状态。

## 可接受格式

- 栅格：GeoTIFF/COG；矢量：GeoPackage/GeoJSON/Shapefile；时序：CSV/Parquet/NetCDF。
- 所有文件必须附数据字典、单位、时区、坐标系、缺失值定义和许可范围。
- 若资料受保密限制，可以先提供脱敏的小范围子区和 2--4 场事件；验证代码与数据目录可保持本地，不上传外部服务。
