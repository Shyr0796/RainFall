## 当前可辩护的创新定位

现有文献已经分别覆盖概率降雨下推、GPU/CA 快速淹没、多尺度计算、数据同化和影响预警，因此这些单项不能单独表述为“首次”。更有辨识度的贡献应落在如下受约束组合上：

> 面向广西数据稀缺村镇，在固定算力和观测预算下，将守恒校准的短临降雨集合，与由地形拓扑、风险和集合误差共同触发的 CA–SWE 异构多尺度求解器耦合；通过异构观测在线更新状态和关键参数，最终输出带可靠度的道路失效、脆弱人群与撤离可达性行动产品，并进行跨事件盲测。

这一定义仍需通过实现细节、消融实验、跨事件验证和性能预算对比来兑现；目前属于**经文献对照后更可辩护的研究定位**，不是已被实验验证的创新性结论。

## 文件约定与质量边界

- PDF 与笔记采用同一文件名主体，例如 `06_...pdf` 对应 `06_...md`。
- source-only 笔记以 `_source_only.md` 结尾，正文给出 DOI 和官方来源链接。
- PDF 只来自出版机构、论文官网或开放预印本平台；所有本地 PDF 均完成可解析性与页数检查。
- 中文笔记是面向 RainFall 的结构化解读，不是论文全文翻译；引用具体数值、公式或结论前仍应回到原文核对。
- 最新题录、下载状态与优先级以 `paper_list.csv` 为准。
